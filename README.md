## Nivela ERP

**[nivelaerp.com.br](https://nivelaerp.com.br)** — "O poder de um ERP, sem a complexidade."

SaaS multi-tenant de gestão para negócios de serviço (barbearias, salões, clínicas, estúdios, pet shops e demais operações por agendamento). O produto nasceu no nicho de barbearias e vem se expandindo para novos segmentos de atendimento.

**Principais capacidades**
- Agendamento público por estabelecimento, sem instalação de app
- Pedidos, fluxo de atendimento e fila de chegada (walk-in)
- Financeiro, caixa diário e relatórios operacionais
- Catálogo de produtos e serviços com controle de estoque
- Planos SaaS, cobrança e administração interna
- Fluxos fiscais e rastreio de documentos
- Permissões por papel e isolamento de dados por cliente (tenant)

**Stack:** Python · Flask · SQLAlchemy + Alembic · PostgreSQL · Jinja2 · Bootstrap 5 · JavaScript · cobrança com Stripe e Asaas · deploy em Railway.

## Automação Moro — WhatsApp com IA e disparos

Solução de **automação de atendimento e comunicação via WhatsApp** para pequenos e médios negócios, construída sobre a **API oficial do WhatsApp (WhatsApp Cloud API / Meta for Developers)**.

**O que resolve**
- Centraliza o atendimento do WhatsApp e reduz trabalho manual repetitivo
- Permite comunicação proativa em escala, dentro das políticas oficiais da Meta
- Entrega automações desenhadas sob medida para o processo de cada cliente

**Como funciona**
- Conexão do número comercial via API oficial da Meta
- **Atendimento com IA**: respostas, triagem e ações a partir de linguagem natural
- **Disparos em massa com templates aprovados pela Meta**: campanhas, lembretes, confirmações e avisos
- Fluxos e integrações personalizados conforme a operação do negócio

**Como é oferecido**

Atualmente entrego a Automação Moro como **solução sob medida** — um projeto personalizado para cada cliente, e não como um aplicativo pronto de prateleira. Frentes disponíveis:
- Automação de WhatsApp com IA
- Disparos de campanhas via templates oficiais (Meta)
- Integrações e fluxos personalizados sob demanda
